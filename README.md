# Silicon

Silicon är en responsiv webbsida byggd utifrån en design i Figma som en del av inlämningsuppgift A och B.

Projektet är byggt med HTML och CSS och är anpassat för desktop, tablet och mobile.

## Mina delar

Jag har arbetat med:
- Header och Hero
- Brands
- App Features
- How Does It Work?
- Features Details
- Testimonials
- FAQ
- Newsletter
- Footer
- Responsiv design för desktop, tablet och mobile
- Light mode och dark mode
